# Портфолио Ксении Кыштымовой

Сайт с проектами из портфолио в Notion. Работает на GitHub Pages без установки зависимостей и сборки.

## Посмотреть на компьютере

В папке проекта запустите:

```sh
python3 -m http.server 8000
```

Откройте <http://localhost:8000>. Чтобы остановить сервер, нажмите `Ctrl+C`.

## Опубликовать на GitHub Pages

После загрузки файлов в ветку `main` репозитория `Glebsly/ksushapd`:

1. Откройте репозиторий на GitHub → **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main**, папку **/ (root)** и нажмите **Save**.
4. Дождитесь завершения публикации. Обычно это занимает несколько минут; ссылка появится в разделе **Pages**.

Адрес сайта: <https://glebsly.github.io/ksushapd/>.

## Обновить портфолио

Главная страница находится в `index.html`, страницы проектов — в папке `cases`, изображения и другие файлы — в `assets`.

Отредактируйте нужный файл и сохраните изменения в ветке `main` через GitHub или Git. GitHub Pages опубликует обновление автоматически. Сохраняйте относительные ссылки на страницы и изображения, чтобы они работали по адресу `/ksushapd/`.

Контент перенесён из экспорта Notion. Дальнейшие изменения в Notion не синхронизируются с сайтом автоматически.
